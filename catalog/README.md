# Catalog

Derived, read-only index of SDK projects and API authorities. Every file here is generated by the hub compiler from pinned source metadata.

## Layout

```text
catalog/
  index.json                    counts, digests, compiledAt, artifact hashes
  sdks/<sdk-family>.json        one SDK project per family
  apis/<api-authority>.json     authority metadata and operation inventory
  operations/<api-authority>.json
  modules/<module>.json
```

## Rules

- Never edit by hand. Fix the source metadata or the compiler, then recompile.
- The owner repository's `sdk-manifest.json` remains the SSOT.
- Every file carries `"generated": true`, a generator, and a schema version.
- `compiledAt` and `pinsDigest` exist only in `index.json`.

## Commands

```bash
node tools/hub.mjs catalog check
node tools/hub.mjs info
```

Read [../specs/CATALOG_SPEC.md](../specs/CATALOG_SPEC.md) before changing an entity shape.
