# Repository Skills

Procedures for maintaining this hub: adding a link, recompiling the catalog, regenerating context, and reviewing a standard change.

## Adding A Skill

1. Create `.sdkwork/skills/<skill-name>/SKILL.md` with `name` and `description` frontmatter.
2. State when to use it, inputs, files or commands it may touch, governing specs, and verification.
3. Keep it under 2,000 tokens. Cite specs; do not copy them.
4. Do not store credentials, generated artifacts, or runtime data.

Hub-maintenance skills stay here. Agent-facing SDK consumption skills are published from `../../context/skills/`.
