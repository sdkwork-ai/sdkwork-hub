## Rules

- File name equals the SDK family, for example `sdkwork-iam-app-sdk.md`.
- Content must not contradict catalog facts: names, versions, packages, operations, auth modes, or maturity.
- Keep it short. Durable platform rules belong in `sdkwork-specs`, not here.
- The compiler merges overrides; do not edit generated references directly.
