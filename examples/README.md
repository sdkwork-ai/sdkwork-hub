# Examples

Minimal consumer snapshots used to prove that the hub context is sufficient. Each example is a small application or service that consumes one or more SDKs through the documented recipes.

Planned:

- `web-react-iam-app`: PC React shell with appbase, IAM login, and one Drive upload.
- `flutter-iam-app`: Flutter shell with IAM login and one paginated list.

Examples are verification fixtures, not templates to copy wholesale.
