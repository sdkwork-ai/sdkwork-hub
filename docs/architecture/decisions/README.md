## Rules

- File name: `ADR-<nnnn>-<kebab-title>.md`.
- A decision states context, decision, consequences, alternatives, and affected specs.
- Superseded decisions remain in place and are marked superseded.
- An accepted decision updates its spec in the same change or names the follow-up.
