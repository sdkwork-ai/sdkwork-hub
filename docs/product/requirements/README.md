# Requirements

Requirement records for the hub. Each record states the need, the acceptance proof, the owning spec, and the phase.

## Format

```text
REQ-<nnnn>-<kebab-title>.md

Status: draft | accepted | implemented
Phase: P0-P5
Spec: specs/<owning spec>.md
Proof: <command or golden task>
```

Requirements are linked from `../prd/PRD.md` section 8.
