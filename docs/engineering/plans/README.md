# Plans

One plan per non-trivial change or phase.

## Format

```text
PLAN-<nnnn>-<kebab-title>.md

Status: draft | active | complete
Phase: P0-P5
Specs: <owning specs>
Scope: <what changes and what does not>
Steps: <ordered, verifiable steps>
Verification: <commands>
```

A plan that changes a boundary must link the ADR.
